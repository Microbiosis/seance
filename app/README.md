# Séance — a local medium that claims to read a brain

A linear probe reads EEG from one sitter and reports a single concept; a local
Gemma 3 4B turns that impression into a message from beyond. The audit tab
shows what happened when we swapped the brain out.

The ghost's words here are transcripts recorded offline with the same local
model; the *impression* is recomputed live from the shipped probe.

Source: https://github.com/Microbiosis/seance
